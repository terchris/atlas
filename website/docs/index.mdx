# Atlas

**Open semantic layer over Norwegian public data.** Atlas aggregates public data about Norway's NGO sector and the humanitarian needs that shape it — from SSB, FHI, Bufdir, and NGO supply registers — into one queryable surface with provenance, citation, and a clean API.

## What you can do with Atlas

- **Find a dataset.** Use [Sources](/sources) above, or search across every source.
- **Query the data.** The [interactive API playground](/api) at `/api` runs against `api-atlas.sovereignsky.no` (PostgREST). Every source has a sample query you can copy into curl, Python, or anywhere.
- **Cite a source.** Every per-source page carries a recommended citation + BibTeX block + permalink.
- **Trace the lineage.** The [dbt docs](pathname:///lineage/) at `/lineage/` show how each `raw.*` table flows downstream into the `marts.*` schema and `api_v1.*` views.

## Conventions

- **Norwegian field names where SSB / FHI / Brreg use them** (`kommune_nr`, `fylke_nr`, `orgnr`) — these are the public-registry canonical forms; we don't anglicise.
- **English column names where Atlas defines them** (`source_id`, `chapter_level`, `service_category_code`).
- **All dates and timestamps in ISO 8601, UTC.**
- **Provenance always present** — every row in `marts.fact_*` carries `source_id` and `updated_at` so you can trace it back.
