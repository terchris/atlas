<div style={{whiteSpace: 'pre-wrap'}}>{"Brønnøysundregistrene's Frivillighetsregisteret holds the ~72,800 Norwegian\norganisations registered as voluntary. Atlas walks it in full and stores each\nrecord verbatim in `raw.brreg_frivillige`, typing out the registrant's own ICNPO\nclassification.\n\n🔴 This is not where Atlas learns which organisations are voluntary. That flag —\n`registrertIFrivillighetsregisteret` — is on 100% of Enhetsregisteret's bulk\nrecords and true for ~72,798 of them, so the NGO population is derived from the\nsnapshot alone with no second API call. This source exists for the attributes\nEnhetsregisteret does not carry: `icnpoKategorier`, `grasrotandel`,\n`innfoertDato`, `vedtekter` and `regnskapsrapportering`.\n\nThat split was designed in deliberately. If this register becomes unavailable,\nthe membership half of Atlas's NGO population survives untouched and only the\nenrichment half needs rethinking.\n"}</div>
