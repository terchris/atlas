## About this source

<div style={{whiteSpace: 'pre-wrap'}}>{"Brønnøysundregistrene publishes every change to Enhetsregisteret as an ordered\nfeed: one record per change, carrying the organisation number, a change type and\na monotonic `oppdateringsid`. Atlas walks it forward daily from a durable\nwatermark, recording each change in `raw.brreg_oppdateringer` and the\norganisation's document at that moment in `raw.brreg_enheter_versions`.\n\nThis is what keeps the bulk snapshot (`brreg-enheter-alle`) from going stale.\nThe snapshot is a point in time; a bulk file cannot express a deletion, because\nabsence from a 1.17M-record file is indistinguishable from a truncated download.\nDeletions arrive here, as `Sletting` and `Fjernet` change types.\n\nThe feed has no retention window — it reaches back to `oppdateringsid` 1 in April\n2018 — so a missed day, week or month catches up completely on the next run.\nCadence is a freshness choice, not a correctness one.\n"}</div>
