## How this catalogue works

Every dataset on Atlas comes from a public Norwegian publisher and is
ingested verbatim into `raw.*`, then shaped into `marts.*` for joinable
queries through PostgREST. The source pages above describe the
upstream — what it covers, when it updates, how Atlas calls it. The
[lineage view](https://atlas.sovereignsky.no/lineage/) shows how each
`raw.*` table flows downstream into the marts and `api_v1.*` endpoints.

If you spot something wrong in a source's metadata, click *Report a
data issue* on the per-source page — that routes to Atlas's GitHub
issues for our-side fixes and to the upstream publisher's own feedback
channel for data-side fixes.
