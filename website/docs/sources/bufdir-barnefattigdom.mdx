## About this source

Barne-, ungdoms- og familiedirektoratet (Bufdir) publishes the Barnefattigdom kommunemonitor on
bufdir.no and ships a single bulk ZIP of `Indikator_*.xlsx` workbooks ("last ned hele datasettet").
Atlas downloads that ZIP (URL discovered from the monitor page), parses sheet `Data` in each
workbook, and loads kommune- and sub-kommune-level time series into `raw.bufdir_barnefattigdom`
so analysts can compare Bufdir's poverty lens with register-based sources such as SSB low-income
statistics.
