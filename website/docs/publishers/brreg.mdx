# Brønnøysundregistrene



The Brønnøysund Register Centre — the Norwegian government agency that
operates the country's central registers. Atlas reads Enhetsregisteret
(every registered legal entity, ~1.17M) and Frivillighetsregisteret (the
voluntary-organisation register, a filtered view of the same entities).
Data released under NLOD 2.0; `organisasjonsnummer` is the join key that
makes organisational data from any Norwegian source line up.

No logo: Brreg's mark is not offered under the same open licence as the
data, so the publisher page renders without one rather than
redistributing it.


[Visit Brønnøysundregistrene →](https://www.brreg.no/)
